## Definition

A set algebra on `X` is a family `A subset P(X)` such that:

```text
X in A
A is closed under complements
A is closed under finite unions
```

Equivalently, it is the finite Boolean closure package generated by the
operations we have been learning.

## Why This Definition Is Economical

We do not include finite intersections as a primitive clause because Gate 44
already established the bridge:

```text
complement closure + finite union closure -> finite intersection closure
```

So the definition is shorter without losing the behavior we need.

## Plain-Language Reading

A set algebra is a selected family of subsets that behaves like a finite
universe of set manipulation.  Once a set is admitted, its complement is
admitted.  Once finitely many sets are admitted, their finite union is admitted.

## Common Failure Modes

- Confusing the concrete family-of-subsets definition with the later abstract
  operation-signature model.
- Forgetting the ambient set condition `X in A`.
- Requiring countable union closure; that is sigma-algebra territory, not set
  algebra territory.
- Listing every Boolean consequence as part of the definition instead of
  deriving it from the economical axiom package.
