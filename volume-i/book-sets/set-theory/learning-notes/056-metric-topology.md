# Gate 56: Metric Topology

## Target

Introduce `def:metric-topology`.

## Statement Shape

Let \(d:X\times X\to\mathbb R\) be a metric on \(X\).

For \(x\in X\) and \(r>0\), define the open ball

\[
  B_d(x,r)=\{y\in X:d(x,y)<r\}.
\]

A set \(U\subseteq X\) is \(d\)-open if for every \(x\in U\) there is
some \(r>0\) such that

\[
  B_d(x,r)\subseteq U.
\]

The metric topology induced by \(d\) is

\[
  \tau_d=\{U\subseteq X:U\text{ is }d\text{-open}\}.
\]

## Why This Gate Exists

This gate connects metric spaces to the Borel machinery.

The pipeline is:

1. metric \(d\);
2. open balls \(B_d(x,r)\);
3. metric-open sets \(\tau_d\);
4. Borel sigma-algebra \(\sigma(\tau_d)\).

That is enough for the later move to \(\mathbb R^n\): the Euclidean metric
induces the usual topology, and the Borel sigma-algebra is generated by its
open sets.

## Common Mistakes

- Thinking an open ball is itself the whole topology.  The topology is the
  family of all sets satisfying the ball-local condition.
- Forgetting the radius must be positive.
- Treating metric topology as a sigma-algebra.  It is a topology; Borel
  generation turns it into a sigma-algebra.
