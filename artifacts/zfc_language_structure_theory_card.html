ZFC as Language, Structure, and Theory

A front-of-chapter model-theory card: first name the formal interface, then show the semantic object, then list the axioms that turn that object into a model of set theory.

Model Theory Bedrock

The Formal Domain of Discourse

Language

Signature ℒ∈ = FOL= + { ∈ } one non-logical symbol
Relation Symbols ∈ : 2 membership is binary
Function / Constant Symbols none strict ZFC has no primitive operations and no primitive named sets

Structure

Form 𝔐 = ⟨ M, E ⟩ M is the universe; E ⊆ M × M interprets ∈
Internal Membership a E b inside 𝔐, this is what “a ∈ b” means
No Axioms Yet ⟨ M, E ⟩ a structure is only data until we ask what it satisfies

Theory

Axiom Set ZFC ⊆ Sent(ℒ∈) sentences written using variables, logic, equality, and ∈
Satisfaction 𝔐 ⊨ ZFC every ZFC axiom is true when ∈ is interpreted as E
Unlocked Vocabulary ∅, {a,b}, ⋃A, 𝒫(A), ⊆ defined or guaranteed after the axioms, not native to ℒ∈
Pedagogical rule: the Language block tells us what may be written, the Structure block tells us what the symbols mean in a candidate universe, and the Theory block tells us which sentences must come out true. The later algebraic cards begin only after this bedrock is in place.

Categorical Shadow

What the ZFC Axioms Start Building

blue: primitive semanticsgreen: object constructorsorange: subset constructorsviolet: later structural interface

Extensionalityturns membership profiles into equality. Categorically, it whispers “subobjects are determined by their elements/predicates.”
Empty Set, Pairing, Union, Power Setguarantee basic object-building operations. These later become bottom, finite joins, indexed unions, and powerset/subobject structure.
Separationturns predicates into subsets of an existing set. This is the first strong bridge from logic to subobject thinking.
Replacementlets definable functional images of sets remain sets. This prepares the later function-image interface.
Infinityguarantees an inductive set, opening the natural-number construction and recursion/induction machinery.
Foundation and Choiceimpose global structural behavior: well-founded membership and selectable representatives where choice functions are needed.
Important guardrail: this diagram is a categorical shadow of ZFC, not a replacement for the formal axioms. The formal theory is still first-order set theory in ℒ∈; the diagram records the recurring structural roles those axioms make available.
