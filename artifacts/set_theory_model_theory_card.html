The Interface of ZFC Set Theory

Language

Signature ℒ∈,∅ = FOL= + { ∈, ∅ } expanded ZFC language used in this chapter
Non-Logical Relations ∈ : 2 membership is the primitive binary relation
Constants ∅ : 0 the empty-set constant, interpreted as the unique set with no members
Function Symbols none union, powerset, pairing, difference, and complement are not primitive function symbols here

Structure

Form 𝔐 = ⟨M,E,e⟩ M is the universe, E ⊆ M × M, and e ∈ M interprets ∅
Interpretations ∈𝔐 = E, ∅𝔐 = e formulas are evaluated using these interpretations
Universe M ≠ ∅ all variables range over M

Native and Unlocked Interface

Native variables, equality, logic, quantifiers, membership ∈, and the empty-set constant ∅
Axiom-Given pairs, unions over sets, power sets, infinite sets, separated subsets, replacement images, choice functions
Derived {a,b}, A∪B, A∩B, A\B, Aᶜ relative to U, A△B, A×B, 𝒫(A)
Later Structure relations, functions, images, preimages, order, lattices, cardinality, quotient objects

Axiom-to-Tool Reading

Existence Axioms Empty Set, Pairing, Union, Power Set, Infinity, Separation, Replacement, and Choice assert that certain witnesses exist.
Uniqueness Mechanism Extensionality turns many existence witnesses into named constructions once their membership condition determines them uniquely.
Guardrail: in this expanded language, ∈ is the primitive relation and ∅ is a constant. The other axioms do not add native function symbols; they guarantee set-forming constructions that we later name and use as operations.
